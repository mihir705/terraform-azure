# PostgreSQL Flexible Server Module

Terraform module to create an Azure Database for PostgreSQL Flexible Server with configurable SKU, storage, backup, optional high availability, VNet integration, and optional private DNS zone.

## Resources created

| Resource | Always created | Notes |
|----------|----------------|-------|
| `azurerm_postgresql_flexible_server` | Yes | PostgreSQL Flexible Server |
| `azurerm_postgresql_flexible_server_database` | No | One per `databases` entry |
| `azurerm_postgresql_flexible_server_configuration` | No | One per `configurations` entry |
| `azurerm_private_dns_zone` | No | When `create_private_dns_zone = true` |
| `azurerm_private_dns_zone_virtual_network_link` | No | Links DNS zone to VNet |
| `random_password` | No | When `generate_password` is used |

| Name | Version |

## Usage

See [terraform.tfvars.example](./terraform.tfvars.example) for copy-paste examples.

### Private PostgreSQL in VNet

Requires a delegated database subnet in the VNet (not included in the default VNet module).

```hcl
postgresql_servers = {
  app = {
    name                  = "my-company-pg-prod"
    resource_group_key    = "app"
    sku_name              = "GP_Standard_D2s_v3"
    administrator_login   = "pgadmin"
    vnet_key              = "main"
    subnet_key            = "database"
    create_private_dns_zone = true

    databases = {
      app = {}
    }

    tags = { Purpose = "application-db" }
  }
}
```

### Public burstable instance (dev / lab)

```hcl
postgresql_servers = {
  dev = {
    name                          = "my-company-pg-dev"
    resource_group_key            = "app"
    sku_name                      = "B_Standard_B1ms"
    administrator_login           = "pgadmin"
    public_network_access_enabled = true

    generate_password = { length = 32 }

    tags = { Purpose = "dev-database" }
  }
}
```

## Environment-level wiring

| Field | Resolves from |
|-------|----------------|
| `vnet_key` + `subnet_key` | Delegated database subnet from VNet module |
| `virtual_network_id` | VNet module for private DNS zone link |
| `nsg_key` | Network security group module (subnet-level) |

## Inputs

| Name | Description | Type | Default | Required |
|------|-------------|------|---------|:--------:|
| `name` | Server name | `string` | — | yes |
| `resource_group_name` | Resource group | `string` | — | yes |
| `location` | Azure region | `string` | — | yes |
| `sku_name` | Server SKU | `string` | — | yes |
| `administrator_login` | Admin username | `string` | — | yes |
| `storage_mb` | Storage in MB | `number` | `32768` | no |
| `backup_retention_days` | Backup retention | `number` | `7` | no |
| `high_availability` | HA configuration | `object` | `null` | no |
| `delegated_subnet_id` | VNet integration subnet | `string` | `null` | no |
| `tags` | Resource tags | `map(string)` | `{}` | no |

## Outputs

| Name | Description |
|------|-------------|
| `server_id` | Server resource ID |
| `fqdn` | Server FQDN |
| `administrator_password` | Generated password (sensitive) |
| `database_ids` | Database IDs by logical name |

## Notes

- **Public access** is disabled by default; set `public_network_access_enabled = true` for lab use, or provide `delegated_subnet_id` / `vnet_key` + `subnet_key` for private deployment.
- Some subscriptions restrict PostgreSQL regions (`LocationIsOfferRestricted`); try another region via `location`.
- Password is generated by default via `generate_password`; store the output securely.
- High availability requires a General Purpose or Memory Optimized SKU.
